업데이트 노트 (간단, 유저용)

v1.0.6.2
- Pak rename recovery: if a mod author renames their .pak file in a new version,
  your previously identified link is now automatically migrated to the new filename.
  No need to re-identify the mod manually.
- Post-download link sync: after downloading an update, the stored fileId and
  Nexus file slot name are refreshed alongside the hash — keeps variant tracking
  accurate for the next update check.
- Bug fix: mods with multiple file entries under the same pak filename (e.g. legacy
  + current upload slots) now always route to the Identify dialog instead of
  silently auto-selecting the wrong variant.
